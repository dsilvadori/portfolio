# Portfolio Daniel Silva

Site estatico em HTML, CSS e JavaScript para GitHub Pages.

## Arquivos

- `index.html`: conteudo do portfolio baseado no curriculo.
- `styles.css`: layout responsivo, cards, filtros e acessibilidade visual.
- `script.js`: menu mobile, filtros de projetos e animacoes leves.
- `assets/hero-wordpress-portfolio.png`: imagem de fundo do hero.
- `assets/daniel-avatar.png`: retrato em formato de desenho com o texto da caneca removido.
- `assets/project-*.png` e `assets/project-*.jpg`: imagens dos cards de projetos.
